# 目录密码与刷新

点开带锁的目录，密码输入框直接出现在该行，下方的文件不会移动。示例密码是 `1234`：

## 目录密码

- 点击加锁目录（或勾选包含它的目录）时，密码输入框出现在该行的大小 / 日期位置，行高不变；勾选在遇到加锁子目录时停下并请求密码
- Enter 提交，Esc 取消；密码错误时在原位提示“密码不正确或无权访问”（OpenList 无法区分密码错误和无权限）
- 钥匙按钮可开启“在此标签页中记住（关闭标签页后失效）”，密码存在 sessionStorage，按 OpenList 地址和目录区分，也覆盖子目录；已记住的目录显示“已记住 · 忘记”
- 保存的密码失效时自动删除，并提示重新输入
- 本次页面中输入过的密码（即使没有记住）在刷新后仍然有效
- 单一 `path` 本身需要密码时，在列表位置显示密码输入框
- 也可以用 `password` 属性预先提供，或在 `sources` 中为单个根目录设置

## 刷新

保留当前列表并调暗，表头下方显示进度条；完成后整体替换，已展开的目录和仍存在的勾选会保留。刷新失败时保留旧数据并提示。

刷新只重新读取 OpenList 的目录缓存（游客没有写权限，无法强制刷新存储）。

## 相关属性

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `password` | `''` | 目录密码，也可以在运行时输入 |
| `rememberPassword` | `true` | 是否提供“在此标签页中记住”开关；`false` 时不写入 sessionStorage |
