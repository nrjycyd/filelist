# 键盘操作

列表可以完全用键盘操作，并且只占一个 Tab 停顿：按 Tab 进入后落在一行上，用方向键在行间移动，再按一次 Tab 离开列表，不管目录展开了多少行。

试一试：点一下下面的筛选框，按几次 Tab，直到某一行出现一圈焦点框，再用方向键、空格、回车操作。键盘焦点在列表里时，底栏右侧会显示按键提示。

## 按键

| 按键 | 文件夹行 | 文件行 | “还有 N 项”行 |
| --- | --- | --- | --- |
| ↑ ↓ | 上一行 / 下一行 | 同左 | 同左 |
| Home / End | 第一行 / 最后一行 | 同左 | 同左 |
| PageUp / PageDown | 跳 10 行 | 同左 | 同左 |
| → | 未展开：展开（加锁的弹出密码框）；已展开：进入第一个子项 | 进入这一行的按钮：预览 → 下载 | 进入按钮：显示更多 → 全部显示 |
| ← | 已展开：收起；否则回到上级文件夹 | 在按钮上：逐个退回，最后回到整行；在整行上：回到上级文件夹 | 同文件行 |
| 空格 | 勾选 / 取消整个文件夹 | 勾选 / 取消 | — |
| 回车 | 展开 / 收起 | 能预览就预览，否则下载 | 显示下一页 |
| 输入文字 | 跳到以这些字开头的行；连续快速输入算一个词，重复同一个字依次跳到下一个 | 同左 | 同左 |
| Ctrl+A（Mac：⌘A） | 勾选全部，再按一次取消 | 同左 | 同左 |
| Esc | 密码框里：取消并回到这一行；预览弹窗里：关闭并回到这一行 | 同左 | — |

工具栏（筛选、刷新、下载 ZIP）和表头（全选、排序）仍是普通的 Tab 停顿，在列表之前。

## 什么时候生效

- **只对键盘生效**：焦点框和按键提示只在用键盘时出现；用鼠标、触屏时外观和操作与以前完全一样，行里的复选框和按钮照常点击
- **Ctrl+A / ⌘A**：只在键盘焦点停在列表的某一行上时改为“全选文件”；在筛选框、密码框里，在页面其它地方，或用鼠标点过列表之后，仍是浏览器自己的全选
- **按键提示**：窄布局（手机）不显示；读屏软件不会读它
- **操作后焦点不丢失**：解锁文件夹、“全部显示”、清除筛选、清除勾选等操作让原来的按钮消失时，焦点会落到最近的合理位置，而不是回到页面开头

## 读屏软件

列表是一个“树形表格”（WAI-ARIA treegrid），读屏软件会读出：

- 进入列表时：标题（例如“键盘示例”）、树形表格、可多选
- 每一行：名称，文件还有大小和日期（“讲义.pdf, 802 B, 2026/11/11”），文件夹有项目数（“示例文件, 5 项”），以及层级、是否展开、是否已勾选
- 表头：每一列的名称，当前排序的列带有升序 / 降序

## 按键提示的文案

按键提示用的是文案 key `keyMove`、`keyExpand`、`keySpace`、`keySelect`、`keyEnter`、`keyOpen`、`keySelectAll`，可以和其它文案一样通过 `labels` 覆盖，见[国际化与文案](../reference/i18n)。
