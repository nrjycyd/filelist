# 批量下载 ZIP

勾选文件或文件夹，工具栏变为操作条，点“下载 ZIP”打包。试试勾选“示例文件”：

- Chrome / Edge（含较新的 Android Chrome）：先弹出系统“另存为”窗口，之后边下载边写入，内存占用很小，不受大小限制
- Firefox、Safari、iPhone：浏览器只能先把文件放进内存再打包。按已选总大小判断：超过 `zipWarnSize` 先确认，超过 `zipMaxSize` 不打包并建议分批
- 打包期间操作条显示进度（大小与文件数），可随时取消；勾选暂时锁定。任一文件失败会整体取消，并弹窗说明是哪个文件、什么原因
- 同时取 4 个文件（顺序不变），减少每个文件的网络等待；进度每 100 ms 更新一次
- ZIP 只存储不压缩（网盘文件多为已压缩格式），支持超过 4 GB（Zip64）；保留目录结构，不同目录的同名文件不会互相覆盖
- 批量 ZIP 通过 `raw_url`（OpenList `/p/` 代理）下载，CORS 保持在 OpenList 源上

## 单文件下载

点文件名或下载按钮：使用 `fs/get` 的 `raw_url`，回退 `/d/`，交给浏览器下载。OpenList 自己的 `/p/`、`/d/` 链接在当前页直接下载、不打开新标签页；存储直链在新标签页打开。

## 相关属性

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `zipWarnSize` | `500`（触屏 `200`） | 内存打包的浏览器超过该大小（MB）先确认；`0` 不提示 |
| `zipMaxSize` | `2048`（触屏 `1024`） | 同上，超过该大小（MB）不打包；`0` 不限制 |
