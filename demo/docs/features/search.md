# 筛选与深度搜索

在搜索框输入关键词，立即筛选已加载的内容。试试输入“答案”，再点“尝试深度搜索”：

<FileList title="筛选与深度搜索" />

```md
<FileList base="https://pan.example.com" path="/课程资料" />
```

- 显示匹配项及其所在目录，关键词高亮；搜索框右侧的 ×（或 Esc）清除筛选，回到原来的展开状态
- 还有未加载的子文件夹时，列表末尾居中显示“只筛选了已加载的内容，**尝试深度搜索**”
- 深度搜索不使用 OpenList 的搜索接口（无需搜索索引）：组件逐个读取未加载的子文件夹（同时 4 个，每次最多 `deepSearchLimit` 个），匹配项出现在原位置，可勾选、打包、预览、下载
- 点过一次即进入**深度搜索状态**，直到清空关键词：更换关键词、刷新、解锁文件夹后都会自动继续；刷新时结果保留，读完一次性替换
- 搜索中可“停止”，达到上限或停止后显示“继续”
- 无法进入的加密文件夹会显示在结果中（带锁，提示“未搜索（需要密码）”），可原地输入密码，解锁后自动搜索其中内容

## 自动深度搜索

挂载目录不大时，可以让输入关键词直接进入深度搜索状态：

```md
<FileList base="https://pan.example.com" deep-search="auto" />
```

## 相关属性

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `deepSearch` | `'manual'` | `'auto'`：输入关键词即自动深度搜索 |
| `deepSearchLimit` | `500` | 每次最多读取的文件夹数，之后可“继续” |
