# 大目录

为了让文章里的列表保持简短，每个文件夹先显示 `pageSize` 条（默认 15）。末尾一行左边是进度“已显示 15 / 260 项”，右边是“显示更多”“全部显示”。展开“照片（260 张）”试试：

<FileList title="大目录" path="/照片（260 张）" />

```md
<FileList base="https://pan.example.com" path="/照片" />
```

- “显示更多”每次多显示 `pageSize` 条；剩余不足一页时只显示“显示剩余 X 项”
- 显示超过第一页后，操作区左侧出现“收起”，回到前 `pageSize` 条；全部显示后末行保留为“已显示全部 X 项 · 收起”
- “收起”出现在左侧，连续点“显示更多”时按钮位置不变；紧接在“全部显示”之后的一次“收起”点击会被忽略，避免双击误操作
- 收起时如果文件夹所在行已滚出屏幕，会滚动回该行（单路径列表回到列表顶部）
- 用箭头收起文件夹，再展开时从第一页开始；刷新则保留已展开的条数
- 数据一次全部取回，只减少渲染：排序后再截取，勾选文件夹 / 全选包含未显示的文件，输入筛选词时显示全部匹配
- 单路径模式的顶层列表同样适用

## 调整条数

```md
<FileList base="https://pan.example.com" :page-size="50" />
<FileList base="https://pan.example.com" :page-size="0" />  <!-- 全部显示 -->
```
