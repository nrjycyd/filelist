# 大目录

为了让文章里的列表保持简短，每个文件夹先显示 `pageSize` 条（默认 15）。被截断时，末尾多一行“⋯ 还有 245 项”，右边是“再显示 15 项”“全部显示”。展开“照片（260 张）”试试：

<FileList title="大目录" path="/照片（260 张）" />

```md
<FileList base="https://pan.example.com" path="/照片" />
```

- 末尾一行和文件行对齐：“⋯”在文件类型那一列，“还有 X 项”在文件名的位置；剩余不足一页时只显示“显示剩余 X 项”；全部显示后这一行消失，列表自然结束
- 显示超过第一页后，在这个文件夹里往下滚动时，文件夹行会停在页面顶部（VitePress 导航栏下方），右侧显示“已显示 30 / 260 项 · 收起”；点“收起”回到前 `pageSize` 条，并回到文件夹行
- 用箭头收起文件夹，再展开时从第一页开始；刷新则保留已展开的条数
- 手机上为“+15 / 全部”，可点区域仍为 44px 高；吸顶的文件夹行在勾选操作条下方
- 数据一次全部取回，只减少渲染：排序后再截取，勾选文件夹 / 全选包含未显示的文件，输入筛选词时显示全部匹配
- 单路径模式的顶层列表同样适用

## 调整条数

```md
<FileList base="https://pan.example.com" :page-size="50" />
<FileList base="https://pan.example.com" :page-size="0" />  <!-- 全部显示 -->
```
